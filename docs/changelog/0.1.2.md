# lnd v0.1.2

Date: 2026-08-31

本版本修复长期 announce 循环在句柄丢失后空转占满 CPU 的问题. 使用 `announce_loop` 或依赖其绑定层的调用方应升级.

## Highlights

- 修复 `announce_loop` 在 shutdown sender 断开后忙等, 避免进程 CPU 长期打到约 1.4 核.
- `AnnounceHandle` drop 后会停止后台续租任务, 不再留下泄漏的 renew loop.

## Upgrade Notes

1. 将 `lnd-core` 升级到 `0.1.2`, 或从 GitHub tag `v0.1.2` 拉取源码.
2. 复用 Rust 核心的 C ABI / Python SDK 随核心一起升级; 独立 Go / Java SDK 不受这次修复影响.
3. 用 `lnd-client --version` / `lnd-server --version` 确认安装版本为 `0.1.2`.
4. 已经空转的进程需要完全退出后重启, 旧任务不会自行恢复.

## Bug Fixes

- API: `announce_loop` 在停止信号到达或 shutdown sender 断开后立即退出, 不再对 `watch::Receiver::changed()` 忙等.
- API: 丢弃 `AnnounceHandle` 时会发停止信号并 abort 后台任务, 租约随后按 TTL 过期.
