# lnd v0.1.1

Date: 2026-08-28

本版本是 `lnd` 的首次公开发布. 它提供基于 HTTP(S) 中心注册表的局域网发现能力, 覆盖 Rust crate, CLI, C ABI, Python SDK, 以及独立的 Go / Java 协议实现.

## Highlights

- 发布 `lnd-core` 到 crates.io, 可直接作为 Rust library 或通过 `cargo install` 使用 CLI.
- 提供 REST + SSE 发现协议, 用中心租约替代组播广播.
- 用 `discovery_domain` 做逻辑隔离, 用自动收集的 `reachability_scopes` 做可达性重叠匹配.
- 跨语言提供 Rust, C ABI, Python, Go, Java 接入面.

## Upgrade Notes

1. 从 crates.io 安装 `lnd-core` 0.1.1, 或从 GitHub tag `v0.1.1` 拉取源码.
2. 先启动 `lnd-server`, 再用 `lnd-client` 或各语言 SDK 注册和发现服务.
3. 用 `lnd-client --version` / `lnd-server --version` 确认安装版本为 `0.1.1`.

## Features

- Rust crate: 提供 `LndClient`, `AnnounceSpec`, `DiscoveryFilter` 和可嵌入的 Axum server.
- CLI: `lnd-server` 支持 TOML 配置, `lnd-client` 支持 announce, discover, watch.
- Protocol: `PUT /v1/nodes/{node_id}` 注册续租, `GET /v1/nodes` 查询快照, `GET /v1/watch` 订阅 SSE 事件.
- Discovery: `discovery_domain` 可选, `reachability_scopes` 默认按本机子网前缀自动收集.
- Bindings: C ABI 和 Python SDK 复用 Rust 核心; Go 和 Java 提供独立协议 SDK.
- Watch: 空闲流不会被有限 HTTP timeout 打断, server 关闭时会结束活动 watch 连接.
- Java SDK: 提供同步和 `CompletableFuture` 异步入口, 关闭 watch 时能及时释放连接.
