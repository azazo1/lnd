# lnd v0.2.0

Date: 2026-09-08

本版本为 Rust client 引入可注入的底层 HTTP 执行器, 方便在宿主项目中复用统一的传输层配置或接入流量监控. 全字段字面量构造 `ClientConfig` 的调用方请先阅读 Upgrade Notes 再升级.

## Highlights

- 新增 `HttpExecutor` 抽象, 可以在外部包装每个请求, 接入流量统计, 指标采集或链路追踪.
- `ClientBuilder` 支持传入外部构建的 reqwest client, 复用宿主项目统一的代理, TLS 和连接池配置.
- 普通请求和 `watch` 长连接是两个独立执行器槽位, 可通过共享 `Arc` 使用同一份统计状态.

## Breaking Changes

- `ClientConfig` 新增 `http_executor` / `watch_http_executor` 字段, 逐字段全量构造 `ClientConfig` 的代码会编译失败. 迁移方式: 为两个新字段补 `None`, 或改用 `..ClientConfig::default()` / `ClientBuilder` 构造. 通过 `ClientBuilder` 或 C ABI / Python 绑定使用的调用方不受影响, 独立 Go / Java SDK 不受影响.

## Upgrade Notes

1. 将 `lnd-core` 升级到 `0.2.0`, 或从 GitHub tag `v0.2.0` 拉取源码.
2. 检查是否存在全字段字面量构造的 `ClientConfig`, 按上述方式迁移.
3. 需要流量监控时, 用 `http_executor` / `watch_http_executor` 传入自定义执行器, 鉴权头由 client 按请求注入, 无需额外处理.

## Features

- API: 新增 `HttpExecutor` trait, `reqwest::Client` 自带实现, 自定义包装类型实现后即可让每个请求经过宿主中间件.
- API: `ClientBuilder` 新增 `http_client`, `watch_http_client`, `http_executor`, `watch_http_executor` 四个方法, `ClientConfig` 新增对应字段.
- API: Authorization 改为按请求注入, 外部执行器收到的请求自动携带鉴权头; 注入外部 client 后请求超时由该 client 控制.
